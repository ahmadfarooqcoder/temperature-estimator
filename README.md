# Temperature Converter

## Purpose
A small Python program for practising Git and GitHub. It converts a temperature from Celsius to Fahrenheit.

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python temperature_converter.py
```

## Example Input
```text
Temperature in Celsius: 25
```

## Example Output
```text
Fahrenheit: 77.0
```
